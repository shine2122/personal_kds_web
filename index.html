BEFORE YOU START

이 실습에서 먼저 이해할 것

한 장의 이미지는 공간의 모든 치수와 보이지 않는 면을 담고 있지 않습니다. 목표는 “완벽한 360도 역설계”가 아니라, 이미지에서 실제로 확인 가능한 디자인 영역을 편집 가능한 3D 공간으로 재구성하는 것입니다.

확인 가능한 영역이 기준

최종 기준 이미지에서 보이는 벽체, 개구부, 가구와 주요 디자인 요소를 중심으로 모델링합니다. 보이지 않는 반대편은 모델을 닫기 위한 최소한의 단순화만 허용합니다.

SketchUp은 편집 가능한 모델

벽·바닥·천장·개구부·고정가구·주요 가구를 Group / Component / Tag와 Material로 정리해 이후 직접 수정할 수 있어야 합니다.

3개의 Scene은 유효한 시점

반대편을 억지로 보여주지 않습니다. 세 Scene 모두 기준 이미지에서 확인 가능한 주요 공간과 디자인 요소가 계속 보이는 범위 안에서 카메라만 변화시킵니다.

먼저, 이 이미지를 3D 모델링 기준으로 써도 되는지 진단

미드저니 이미지는 시각적으로 매력적이어도 원근, 벽·천장 접합, 가구 두께, 반복 구조, 개구부 위치가 실제 3D에서는 성립하지 않을 수 있습니다. 따라서 처음부터 모델링하지 않고 건축적 오류를 찾고, 수정이 필요한 부분을 먼저 확정합니다.

원근과 카메라

하나의 실제 카메라로 재현 가능한지, 소실 방향과 수직선이 서로 충돌하지 않는지 확인합니다.

공간과 객체의 성립

벽·바닥·천장·개구부·가구가 서로 관통하거나 끊기지 않고 실제 3D 공간으로 연결되는지 확인합니다.

수정 우선순위

작은 장식 오류보다 3D 구조와 치수 추정에 영향을 주는 문제를 먼저 찾아 수정 대상으로 지정합니다.

Midjourney 이미지 · 3D 모델링 적합성 진단 
첨부한 미드저니 인테리어 이미지를 나중에 SketchUp에서 편집 가능한 건축·인테리어 3D 모델로 재구성하려고 해.

지금은 SketchUp 모델을 만들지 말고, 먼저 이 이미지가 3D 모델링 기준 이미지로 사용하기에 적합한지 건축적·기하학적으로 진단해 줘.

다음을 한 번에 검토해 줘.
- 카메라와 원근: 수직선, 수평선, 소실 방향, 화각의 일관성
- 공간 셸: 바닥, 천장, 주요 벽체, 기둥, 문·창·개구부의 연결 관계
- 객체 오류: 관통, 부유, 중복, 반복 생성, 비정상적 두께, 뒤틀림
- 스케일과 비례: 문, 의자, 테이블, 카운터 등 익숙한 요소 사이의 현실적인 크기 관계
- 사용 가능성: 출입, 통로, 가구 간격 등 이미지에서 확인 가능한 기본 공간 성립 여부
- 가려진 영역: 3D 모델을 만들 때 반드시 추정해야 하는 부분
- 카메라 재현성: SketchUp에서 원본과 유사한 Scene을 만들 수 있는지

결과는 다음 형식으로 정리해 줘.
1. 진행 판단: 바로 사용 가능 / 일부 수정 후 사용 권장 / 기준 이미지로 사용하기 어려움
2. 모델링을 방해하는 핵심 문제: 중요도 순 최대 7개, 화면상의 위치와 이유 포함
3. 수정해야 할 항목: 유지 / 삭제 / 이동 / 정렬 / 형상 수정으로 구분
4. 이미지 수정용 지시문: 카메라 구도와 디자인 콘셉트는 최대한 유지하고 구조적으로 성립하지 않는 부분만 교정하는 하나의 통합 지시문
5. 수정 이미지 이후 확인할 불확실성: 실제 치수가 필요한 항목 / 비례로 계산 가능한 항목 / 사용자 판단이 필요한 항목

중요:
- 이미지가 예쁜지 평가하지 마.
- 실제 치수나 보이지 않는 구조를 확정값처럼 만들어내지 마.
- 작은 장식 오류보다 공간 구조와 모델링 정확도에 영향을 주는 문제를 우선해 줘.
- 아직 SketchUp MCP를 호출하지 마.
다음: 수정이 필요하면 제시된 통합 지시문으로 기준 이미지를 먼저 교정합니다. 수정 이미지는 다음 핵심 프롬프트에서 다시 검증하면서 실제 3D 모델링 기준을 확정합니다.
WORKFLOW · PROMPT 02–03

수정 이미지에서 모델링 기준을 확정하고 SketchUp 3D와 3개 Scene으로

수정된 이미지를 바로 모델링하지 않습니다. 먼저 실제 치수 기준을 정하고, 비례·구조·재질을 모델링 명세서로 확정한 뒤 SketchUp 모델을 생성합니다. 모델링이 끝나면 이미지에서 신뢰할 수 있는 범위 안에서 3개의 Scene도 함께 구성합니다.

핵심 프롬프트 2 · 치수 · 비례 · 구조 · 재질을 모델링 명세서로 확정

수정된 이미지를 첨부합니다. 실제로 알고 있는 치수가 있다면 함께 알려주는 것이 가장 정확합니다. 예: 천장고 2700 mm, 문 폭 900 mm, 테이블 폭 1800 mm.

정확한 절대 치수에는 기준값이 필요합니다. 단일 투시 이미지에서 모든 실제 치수를 정확하게 복원할 수는 없습니다. 최소 1개, 가능하면 2~3개의 실측 또는 설계 치수를 기준으로 제공하면 나머지 요소를 비례 계산할 수 있습니다.
수정 이미지 → 3D 모델링 명세서 
첨부한 이미지는 앞선 진단을 반영해 수정한 최종 기준 이미지다.
이 이미지를 SketchUp 3D 모델로 만들기 전에, 한 번 더 건축적으로 검증하고 정확한 모델링 기준을 정리해 줘.

내가 별도로 알려준 실제 치수가 있다면 그것을 최우선 기준으로 사용해.
실제 치수가 제공되지 않았다면 임의로 '정확한 치수'라고 단정하지 말고, 먼저 기준 치수로 사용할 수 있는 요소를 제안하고 내 확인을 받아.

다음을 하나의 모델링 명세서로 작성해 줘.

A. 수정 이미지 재검증
- 이전에 문제가 되었던 원근, 벽·천장 연결, 개구부, 가구 충돌 등이 해결되었는지 확인
- 아직 남아 있는 구조적 모순이 있다면 모델링 전에 먼저 알려줘

B. 기준 치수와 스케일
- 내가 제공한 실측/설계 치수를 목록화
- 각 기준 치수가 이미지에서 어느 요소에 해당하는지 표시
- 기준 치수를 이용해 나머지 주요 치수를 비례 계산
- 모든 수치는 다음 상태 중 하나로 표시
  [확정] 사용자가 제공한 실제 치수
  [계산] 확정 치수와 이미지 비례로 계산한 값
  [추정] 일반적인 건축·가구 치수에 근거한 임시 값
  [미확정] 이미지 한 장으로 판단하기 어려운 값
- 단위는 mm로 통일

C. 주요 치수표
- 전체 공간 폭 / 깊이 / 천장고
- 주요 벽 길이
- 문·창·개구부 폭과 높이
- 기둥 및 주요 구조체 크기
- 붙박이 가구의 폭·깊이·높이
- 주요 가구의 폭·깊이·높이
- 통로와 가구 사이의 주요 간격

D. 비례와 정렬 규칙
- 반복 모듈, 중심선, 정렬선, 대칭 여부
- 벽체와 가구의 간격 관계
- 곡면 반경 또는 제어 가능한 기준 치수
- 이미지에서 보이는 주요 높이 레벨

E. 공간 구조
Floor / Wall / Ceiling / Column-Structure / Door-Window-Opening / Built-in / Loose Furniture / Lighting / Decor 순으로 계층화하고,
각 요소의 위치 관계, 형상, 연결 요소, 보이지 않는 면의 단순화 방식을 설명해 줘.

F. 재질 명세
각 주요 재료마다 Material ID / 적용 위치 / 재료 종류 / 기본 색·톤 / 광택 또는 거칠기 / 표면 특성 / 확실성 여부를 정리해 줘.

핵심 프롬프트 3 · SketchUp 모델 생성 + 자체 검증

모델링 명세서의 미확정 값을 확인한 뒤 실행합니다. 구조 생성과 검토를 하나의 프롬프트 안에서 진행하되, Codex가 임의로 치수를 변경하지 못하도록 명세서를 기준으로 고정합니다.

확정 명세 → SketchUp 3D 
앞에서 승인한 최종 모델링 명세서를 기준으로 SketchUp MCP를 사용해 현재 열린 모델에 3D 공간을 만들어 줘.

가장 중요한 규칙:
- 승인한 [확정] 치수는 임의로 변경하지 마.
- [계산] 치수는 명세서 값을 사용하되 기준 치수와 비례가 맞는지 확인해.
- [추정] 값은 수정하기 쉬운 형태로 만들고 추정값임을 알 수 있게 해.
- [미확정] 항목을 임의로 크게 확장하거나 새로운 디자인으로 만들지 마.
- 최종 기준 이미지에서 보이지 않는 반대편이나 뒷면은 주요 디자인 영역으로 새로 창작하지 마.

작업 순서:
1. 모델 단위와 원점 확인
2. Floor / Wall / Ceiling / Column 등 큰 공간 셸 생성
3. Door / Window / Opening 생성
4. Built-in 생성
5. 주요 Loose Furniture 배치
6. 이미지에서 확인 가능한 주요 조명기구와 디테일 형상 생성
7. 승인한 재질 명세에 따라 주요 Material 적용
8. Group / Component / Tag 정리
9. 전체 모델 자체 검증
10. 렌더링에 사용할 SketchUp Scene 3개 생성

모델링 원칙:
- 각 객체는 편집 가능하도록 그룹 또는 컴포넌트로 분리
- 반복 요소는 가능한 경우 Component 사용
- 실제 제작에 필요한 기본 두께 유지
- 보이지 않는 영역은 과도하게 상상하지 말고 단순화
- 이미지에 없는 벽, 창, 문, 큰 가구를 임의로 추가하지 않음
- 곡면은 시각적 인상을 유지하면서 편집 가능한 수준으로 생성
- 객체와 재질 이름은 읽기 쉬운 영문으로 정리
- 재질은 앞서 확정한 Material Specification을 기준으로 적용

자체 검증:
- 전체 폭·깊이·천장고가 명세와 일치하는지
- 주요 개구부 치수가 일치하는지
- 가구와 붙박이 요소의 크기·간격이 명세와 일치하는지
- 벽/가구 관통, 뒤집힌 면, 중복 객체가 없는지
- 주요 Material이 올바른 객체에 적용되었는지

[SketchUp Scene 3개 생성]

세 Scene은 모두 최종 기준 이미지에서 실제로 확인 가능한 주요 공간과 디자인 요소를 중심으로 구성해.
이미지에 나타나지 않아 추정으로 만든 반대편이나 뒷면을 주요 렌더링 대상으로 사용하지 마.

View_01_Reference
- 최종 기준 이미지와 가능한 한 동일한 카메라 위치, 눈높이, 시선 방향, 화각과 프레이밍
- 가장 중요한 기준 Scene

View_02_Alternate
- View 01에서 좌우 방향으로 적절히 이동한 대각 시점

- 원본 이미지에서 확인 가능한 요소들이 충분히 남아 있어야 함

View_03_Composition
- 같은 모델링 영역 안에서 카메라 위치, 거리, 높이 또는 화각을 달리한 또 하나의 유효한 구도
- 전체 공간을 조금 더 넓게 보여주거나 핵심 디자인 요소가 더 잘 보이는 방향 중 적합한 것을 선택
- 미확정 영역이나 비어 있는 반대편이 화면의 주요 부분을 차지하지 않게 함

Scene 공통 규칙:
- 모델의 치수, 비례, 구조, 객체 위치와 재질은 변경하지 마.
- 세 Scene은 카메라만 변경해.
- 동일한 Tag 표시 상태와 Style을 유지해.
- 서로 거의 같은 뷰가 되지 않도록 하되, 모두 신뢰할 수 있는 모델링 영역 안에 머물러.
- 수직선이 과도하게 기울어지지 않도록 현실적인 건축 사진 구도를 사용해.

Scene 이름:
- View_01_Reference
- View_02_Alternate
- View_03_Composition
